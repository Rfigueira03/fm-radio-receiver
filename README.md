# FM Radio Receiver

## Overview

This project consists of the design and implementation of a functional FM radio receiver developed during my Bachelor's degree in Electronics, Telecommunications and Computer Engineering.

The receiver was designed, assembled and experimentally validated in laboratory conditions.

## Technologies

- Analog Electronics
- RF Electronics
- LTSpice
- PCB Design
